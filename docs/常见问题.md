# 常见问题

## 打开就报错 / 一闪就没了

1. 确认是**解压后**再双击，不要直接在压缩包里双击
2. 确认 `_internal` 文件夹和 exe 在同一层，缺了打不开
3. 如果提示 `Could not create temporary directory`：那是旧版「单文件 exe」的问题。
   本版是文件夹模式（`--onedir`），不会出现；如果还报，说明解压不全，重新完整解压一次

## 提示 "Windows 已保护你的电脑" / SmartScreen 阻止

未签名程序的标准提示，**不是病毒**。处理方式任选：

- 点「更多信息」→「仍要运行」
- 双击旁边文件夹里的 `启动.bat`
- 右键 exe → 属性 → 底部勾「解除锁定」→ 确定

## 杀毒软件报毒

PyInstaller 打包的 exe 经常被误报，加白名单即可。不放心可以直接跑源码（`python tvbox_finder.py`）。

## 状态条一直在转

正在检测，全量约 30~40 秒。点左下「▸ 检测日志」能看到实时进度。极少数情况是网络断了，看日志有没有一堆连接失败。

## 配置加载了但没有站点 / 站点空白

1. 换左边「④ 备选配置源」里其他地址再试
2. **老安卓电视**：确认勾了「复制 http 地址」，http 和 https 用错是这种症状最常见的原因

## 站点有分类但点进去没内容

源站自己的问题（接口挂了或改了路径），换个源即可。

## 直播有声没画面

多半是 AVS 编码的线路，很多盒子放不了。工具有编码过滤（只留 H.264 / H.265），
如果某条线路仍然只有声音，说明它的 PMT 信息不完整，换一条即可。

## 直播打不开

- 先确认 http 勾选是否正确（老安卓要勾，安卓 9 以上不用）
- 精选直播里很多线路是**中国移动 IPTV CDN**，移动宽带才稳
- 右下「④ 备用直播源」里有别的列表，双击复制试试

## 青海卫视为什么没有

目前没找到稳定可用的青海卫视源，所以卫视固定 24 个里不含青海。
湖南卫视、广东卫视因为经常是录播流，也排除了。

## 给的地址每次都不一样

正常的。源站会换域名、会挂，工具每次都会重新测活、重新挑最快的那个。
自建服务器之后，电视上填的是**你自己的固定地址**，背后的源换了也不用改电视。

## 一定要自建服务器吗

不必须。工具本身能直接给出可用的公开地址。
自建的好处是：电视永远只填一个地址，而且可以加分类过滤、兼容老安卓。

## 检测要连外网吗

要。所有配置源和直播源都是公网地址，检测本身就是实实在在去请求它们。

## 会不会收集我的信息

不会。工具只是拿公开源地址发请求测速，没有上报、没有统计。
