# 打包成 exe

打包用 PyInstaller。**必须用 `--onedir`**，不要用 `--onefile`。

原因：`--onefile` 的 exe 启动时要把自己解压到临时目录，在一些机器上会报
`Could not create temporary directory` 直接打不开；`--onedir` 没有这个问题。

## 一、准备

```powershell
python -m pip install pyinstaller
```

## 二、打包

在 `src/` 目录下执行：

```powershell
$ico = (Resolve-Path "..\assets\tvbox.ico").Path
$ver = (Resolve-Path "version_tool.txt").Path

python -m PyInstaller --noconfirm --clean --onedir --windowed --name "TVBox地址工具" `
  --icon $ico --version-file $ver `
  --add-data "..\assets\tvbox.ico;assets" `
  --add-data "数据\source_index.json;数据" `
  --hidden-import source_finder --hidden-import merge_warehouse `
  --hidden-import patrol --hidden-import owner_auth `
  --distpath "..\dist" --workpath "..\buildT" --specpath "..\buildT" `
  share_entry.py
```

打完在 `dist\TVBox地址工具\` 下面。

## 三、补齐同级文件

PyInstaller 只打包 exe 和 `_internal`，配置文件要手动放到 exe 同级目录：

```
dist\TVBox地址工具\
├── TVBox地址工具.exe
├── _internal\
├── sources.json      ← 从 src/ 复制
└── 启动.bat          ← 可选，双击运行用的兜底
```

## 四、压缩发布

```powershell
Compress-Archive -Path "..\dist\TVBox地址工具" -DestinationPath "..\dist\TVBox地址工具-分享版.zip" -Force
```

## 五、注意

- `share_entry.py` 是分享版入口，它会把 `ALLOW_PUBLISH` 关掉，防止别人的工具往你的服务器发配置
- 打出来的 exe 没有签名，用户首次运行会有 SmartScreen 提示，属于正常现象
- 图标必须是 .ico，`.png` 直接给 `--icon` 会报错
