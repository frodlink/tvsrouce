# 使用说明（v1.6）

## 一、先解压

把 `TVBox地址工具-分享版.zip` 解压出来，进入解压后的文件夹，双击里面的 `TVBox地址工具.exe`。

**不要只把 exe 单独拖出来**，旁边的 `_internal` 文件夹是程序的一部分，缺了打不开。

## 二、打开工具后会做什么

打开工具不会立刻检测，需要点按钮。有云端配置（填了 `cloud.json`）时默认流程是：

1. 读取 `custom_config.json`（如果存在），刷新里面站点的首页延迟并排序
2. 把「配置 + 直播」合并后发布到云端，得到一个固定地址
3. 轻量校验云端现有的直播频道，可用率低于 85% 才自动全量重建

**没有云端配置时**（也就是拿到的分享版，`cloud.json` 没填），会自动改成全量检测，约 30 秒：
把十几个公开配置源和几个直播列表都测一遍，左边给出最好的那个配置地址，右边给出整理好的直播地址。

## 三、界面逐项说明

### 左栏（配置）

| 位置 | 内容 | 怎么用 |
|---|---|---|
| ① 精选配置地址 | 体检后选出的最好地址；接了自建服务器就是你的固定地址 | **点「复制」，填进 TVBox** |
| ② 备用：源站直链 | 配置源站的原始地址 | 固定地址打不开时临时用 |
| ③ 配置详情 | 站点数、解析数、延迟、发布时间 | 看状态 |
| ④ 备选配置源 | 全部通过体检的配置源 | **双击一行**复制该行地址 |

### 右栏（直播）

| 位置 | 内容 | 怎么用 |
|---|---|---|
| ① 精选直播地址 | 工具自己整理的 m3u（央视 + 卫视 + 体育） | 配置源自带的直播不满意时填这个 |
| ② 备用：直播直链 | 精选直播的备用地址 | 精选直播挂了时临时用 |
| ③ 直播详情 | 频道数、央视/卫视数量、平均延迟 | 看状态 |
| ④ 备用直播源 | 几个现成的直播列表 | **双击一行**复制 |

### 底部

- 左侧「▸ 检测日志」：默认折叠，展开可看实时进度
- 右侧「联系我」「支持我」
- 中间「站长工具」：看下面的说明

## 四、三个按钮的区别

| 按钮 | 耗时 | 影响范围 |
|---|---|---|
| 只刷新配置 | 约 10 秒 | 只动左栏，右边直播完全不动 |
| 只刷新直播 | 约 20 秒 | 只动右栏，左边配置完全不动 |
| 检测全部 | 约 30 秒 | 两边一起全量重测 |

> 只想换配置就用「只刷新配置」，想重建直播就用「只刷新直播」，
> 不确定或者刚换了网络环境，点「检测全部」。

## 五、http 开关（老安卓必看）

窗口顶部状态条右侧有一个全局开关：**「复制 http 地址（老安卓电视勾选）」**。

- **Android 4.4 及更早**（很多老 TCL、创维、小米盒子）：必须勾选，用 `http://`
  这些系统不认新版 HTTPS 证书，用 https 地址会加载失败
- **Android 9 以上**：两种都行，不勾也可以

勾一次，左右两栏所有地址一起变成 `http://` 版本，鼠标移到旁边的「?」有说明。

## 六、把地址填进 TVBox

不同壳的入口不太一样，找「配置地址 / 接口地址 / 订阅地址」这类选项：

- **影视仓**：设置 → 配置 → 配置地址 → 粘贴 → 确定，回桌面再进
- **TVBox / 猫影视**：设置 → 配置地址 → 粘贴 → 确定
- **FongMi / 影视**：设置 → 接口设置 → 粘贴 → 确定

粘贴完一定要**退到桌面再打开一次**，配置才会真正加载。

## 七、站长工具（进阶）

底部「站长工具」是给自己维护云端配置用的，需要密码：

- 每次启动后第一次点需要输入密码，本次运行内不再重复询问
- 密码只存 PBKDF2 哈希（盐 + 20 万次迭代），文件在 `%APPDATA%\TVBox地址工具\owner.dat`
- 忘记密码或换电脑：删掉 `owner.dat`，下次点会要求重新设置
- **分享版不含这个文件，「站长工具」按钮本来就是禁用的**

窗口里三个功能：

| 功能 | 说明 |
|---|---|
| 一键巡检 | 站点体检 → 不够 8 站从候选池补 → 直播巡检 → 可用率低于 85% 才重建 → 备份并发布 → 云端回读 |
| 只合并站点 | 从候选池择优合并站点，不动直播 |
| 恢复上次配置 | 回滚最近一次巡检/合并前的备份 |

## 八、源接口工具

顶部「源接口工具」是独立窗口，从多个接口发布页采集可用的单仓配置地址，
带进度条和筛选，双击一行即可复制。
